# Za_gorodom66

Статический адаптивный сайт по предоставленному макету. HTML, CSS, JavaScript; установка зависимостей и сборка не нужны.

## Открыть

Откройте `index.html` в браузере. Все фотографии и оформление локальные, внешних CDN и API нет.

## Редактировать

- Тексты, навигация и подписи: `index.html`.
- Цвета: переменные в начале `css/style.css`. Размеры десктопной композиции привязаны к ширине исходного макета 720 px.
- Фотографии: `assets/images/`. Главное фото: `house.webp`, терраса: `terrace.jpg`, спальня: `bedroom.jpg`.
- Бронирование: все три кнопки в `index.html` содержат прямую ссылку `https://homereserve.ru/K5CI9wqkcQ`. Переход происходит в той же вкладке без уведомлений и промежуточных окон. Для изменения адреса замените ссылки в этих трёх элементах `<a>`.
- Контакты: блок `contact-panel` в `index.html`. Номер копируется по нажатию; адрес для копирования находится в `data-copy-phone`. Соцсети открываются в новой вкладке. WhatsApp использует прямую ссылку на чат вместо перехода через 2ГИС.
- Иконки: SVG-символы в начале `index.html`.

## Размещение на Beget / Timeweb

Загрузите `index.html`, папки `css`, `js`, `assets`, а также `favicon.ico` и `robots.txt` в корневую папку сайта (обычно `public_html`). Node.js и сервер приложений не нужны. Включите HTTPS в панели хостинга.

Домен пока не указан, поэтому sitemap.xml не создаётся. После подключения домена добавьте sitemap.xml с фактическим адресом главной страницы и строку Sitemap в robots.txt. Проверьте текст про 2ГИС перед публикацией: он перенесён из макета, источник фотографий отдельно не проверялся.

## Отличия от макета

Оригинальные шрифт, иконки и прозрачные изображения листвы не предоставлены. Использован системный Arial, близкие контурные SVG-иконки и размытая векторная листва. Кадрирование адаптировано к предоставленным фотографиям. Фото спальни заменено на предоставленный широкий снимок 1610 × 977. Для более точного совпадения нужны исходный шрифт и декор.

Адаптация для смартфона сделана на основе десктопной композиции; отдельный мобильный макет не предоставлен.
